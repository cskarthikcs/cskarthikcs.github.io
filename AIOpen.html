Below is a list of open problems that I care about. If an AI model solves any of them in the future, I would be very grateful to be informed, so that I can digest and verify the proof and help communicate the result if needed.

  1. Prove the Parameterized Inapproximability Hypothesis (PIH): Gap-2-CSP, parameterized by the number of variables, is W[1]-hard.
  2. Prove logarithmic-factor FPT inapproximability for Parameterized Set Cover problem.
  3. Prove or disprove conditional subquadratic lower bounds for some constant-factor approximation of the Euclidean Closest Pair problem.
